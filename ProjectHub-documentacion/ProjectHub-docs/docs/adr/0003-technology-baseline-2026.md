# ADR 0003 — Línea base tecnológica

## Estado

Aceptada

## Fecha

2026-10-01

## Decisión

El proyecto parte de Java 21, Maven y Spring Boot 4.x estable.

Al crear el proyecto Spring se utilizará la versión estable compatible disponible en ese momento, evitando fijar una versión antigua por costumbre.

## Referencia de inicio

A fecha 2026-10-01, la documentación oficial de Spring muestra Spring Boot 4.1.1 como versión estable más reciente y especifica compatibilidad con Java 17 a 26 y Maven 3.6.3 o posterior.

## Consecuencia

El entorno actual con Java 21 y Maven 3.9.12 es válido para la línea base del proyecto.
